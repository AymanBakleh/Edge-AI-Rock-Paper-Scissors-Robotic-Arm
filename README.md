# InMoov-RPS-Edge-AI-Rock-Paper-Scissors-Robotic-Arm
An interactive, low-latency, edge-AI robotic system that plays Rock, Paper, Scissors in real time against human opponents.
The project utilizes an Ultraleap Leap Motion Controller 2 for high-fidelity hand tracking, an Edge Impulse TinyML model running locally on a Raspberry Pi, and a 3D-printed InMoov humanoid robotic arm for biomimetic physical actuation.
